# 🧬 Hi, I'm Aurorawins 

I'm an evolutionary biologist interested in how **genomic variation shapes phenotypic diversity and adaptation**.  
My work combines **comparative genomics**, **phylogenomics**, and **computational image analysis** to explore the molecular basis of evolutionary change — especially in **spiders (Salticidae)**.

---

### 🔍 Research Interests
- Evolutionary genomics and adaptive radiation  
- Color pattern evolution and sensory ecology  
- Phylogenetic inference and comparative methods  
- Bioinformatics pipelines for large-scale genomic data  

---

### 🧪 Current Focus
I'm currently working on:
- Comparative genomics of **Jumping spiders**  
- Evolutionary mechanisms of **color diversification** in *Siler* species  
- Developing image-based pipelines for **quantitative color analysis**
